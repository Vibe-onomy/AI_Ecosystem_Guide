# Brand Lanes — Master Content Router

This skill has two jobs, in order:
1. **Decide the lane** — platform, audience, and voice for the piece.
2. **Route to the specialist skill** that should actually produce it.

No writing skill on this account should be invoked for Vibe Align content
without passing through this router first. That is what keeps five writing
skills from fighting over the same request.

## Step 1 — Determine the lane

Ask (or infer from context) three questions:
- **Where will this live?** (LinkedIn, blog, newsletter, ad, column, DM, bio)
- **Who is it for?** (clients, peers, cold audience, existing list)
- **What is it doing?** (authority, lead-gen, nurture, launch, brand play)

State the chosen lane in one line before any content is produced, e.g.:
`Lane: LinkedIn / cold audience / authority — Vibe Align voice, column-adjacent.`

If the piece doesn't fit any lane, say so — "stay in lane" means it's fine
to NOT post something.

## Step 2 — Route to the specialist

| The task is… | Route to | Notes |
|---|---|---|
| A Dear Vibe Align column, diagnosis/prescription piece, or anything in the "biz therapy" format | `dear-vibe-align` | Format owner. Also owns ad copy and brand messaging in the column voice. |
| A blog post / SEO article (esp. from a YouTube video) | `seo-blog-post-writer` | vibealign.co only. |

| Just the opening lines of a LinkedIn post | `linkedin-hook-writer` | Hooks only, 8–10 variants. |
| Full social posts / platform-native content | `mikke-social-content-v3` plugin | |
| Persuasion-heavy copy (offers, sales pages) | `vibe-persuasion` plugin | |
| Webinar scripts and funnel assets | `perfect-webinar-builder` | |
| SEO articles, listicles, comparisons, topical clusters | Doser stack SEO writers (Claude Code) | Production factory, not chat. |
| Email newsletters, sequences, sales emails | Doser stack email skills (Claude Code) | Assessment is the default email offer. |
| Short-form video scripts and captions | Doser stack `Short Form Video Script Creator` | |
| Landing pages, web pages, CRO passes | Doser stack `Landing Page Designer` + `CRO Skill` | Guardrails block applies. |
| Lead magnets | Doser stack `Lead Magnet Creator` | |
| Carousels and social graphics | Doser stack `Social Media Graphics Generator` (runs the Vibe Align carousel system) | |
| ANY final draft, before it goes anywhere | `anti-slop` (stack version) | Mandatory last pass. |

Two rules about the table:
- Announce the hand-off ("Routing to dear-vibe-align") so it's auditable.
- If two skills could apply, the more specific format owner wins
  (e.g. a column about SEO is `dear-vibe-align`, not `seo-blog-post-writer`).

## Step 3 — Voice constants (apply in every lane)

Whatever the lane, the voice is Mikke's: direct, witty, authority-forward,
zero AI slop. Lanes change register and format, never the person. If content
must sound like someone other than Mikke (client work, guest work), that is
an explicit exception the user must state — never assume it.

## Publishing guardrail

This router and every skill it routes to produce **drafts**. Nothing is
scheduled, posted, sent, or deployed without the user explicitly approving
that specific piece in that specific conversation turn.
