# Case Study Builder — the proof supply chain

Landing pages, proposals, and posts all have Proof sections. This skill
keeps them stocked.

## Mode 1 — Collect (no material yet)

Generate a short proof-collection kit for a just-finished engagement:
- 5 interview questions that surface specifics, not adjectives
  ("What number changed?" "What did you stop doing?" "What would have
  happened if you'd waited a year?")
- A copy-paste ask message in Mikke's voice (direct, warm, zero groveling)
- A consent line requesting written permission for named use, with a
  de-identified fallback option

## Mode 2 — Format (material exists: call notes, emails, a rambling voice memo)

Produce three sizes from one input:
1. **Full case study** — Situation (their words) → Diagnosis (what was
   actually wrong) → Prescription (what was done) → Results (numbers first)
   → Client quote → One-line CTA. Business-therapy structure, 400–700 words.
2. **Proof block** — 2–3 sentences + one stat, drop-in ready for
   landing-page-builder and proposal-builder.
3. **Social snippet** — the single strongest quote or stat, formatted for
   vibealign-content / linkedin-hook-writer to build a post around.

## Compliance guardrails (non-negotiable — BH context)

- **De-identify by default.** Behavioral health clients and programs are
  never named, and details that could identify a program (county + size +
  service type together) are generalized unless written consent explicitly
  covers them. 42 CFR Part 2 instincts apply to marketing, not just records.
- Track consent status on every piece: NAMED (written consent on file) /
  DE-IDENTIFIED / DRAFT-ONLY. Anything without a status is DRAFT-ONLY.
- Results are stated only as the client stated them. No rounding up, no
  "up to," no implied clinical outcomes.
- This skill produces drafts. Nothing publishes anywhere without the user
  approving that specific piece.

## Hand-offs

- Proof blocks → landing-page-builder, proposal-builder
- Social snippets → vibealign-content, linkedin-hook-writer
- Final voice pass → anti-slop
